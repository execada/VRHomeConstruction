# E2E-тесты (Playwright)

Ключевые сценарии в настоящем браузере (Chromium Playwright, безголовый режим).
Один раз установите браузер: `npx playwright install chromium`
(или используйте установленный Google Chrome: `E2E_CHANNEL=chrome npm run test:e2e`).

| Файл | Что проверяет |
|------|---------------|
| `guest.spec.ts` | главная без входа, окно входа/регистрации, ошибка неверного пароля, шаблоны без входа, редиректы старых адресов, 404 |
| `auth.setup.ts` | вход тестовым аккаунтом через интерфейс (сессия сохраняется в `e2e/.auth/`) |
| `dashboard.spec.ts` | проект из шаблона, избранное, теги и поиск, папки, удаление с подтверждением, вид списком, настройки и тема |
| `editor.spec.ts` | размещение мебели кликом в 3D (на полу, внутри комнаты), отмена/повтор, 2D-план со стенами, автосохранение и восстановление |

## Запуск

1. Запустите бэкенд (порт 8080) — `./run.sh` или `go run ./cmd/server` в `backend/`.
2. Создайте тестовый аккаунт на **локальном** бэкенде и запишите его в `e2e/.env.e2e.local`
   (файл в `.gitignore`, не коммитьте его):

   ```
   E2E_EMAIL=...
   E2E_PASSWORD=...
   ```

3. `npm run test:e2e` — дев-сервер поднимется сам (или используется уже запущенный на :3000).
   Против другого стенда: `E2E_BASE_URL=https://staging.example.com npm run test:e2e`.

Отчёт: `e2e/report/index.html`, трассировки упавших тестов — `e2e/results/` (`npx playwright show-trace …`).
Тесты создают проекты с префиксом «E2E» и удаляют их за собой.
